## Local preview

Open `index.html` in your browser, or start a local static server:

```bash
python -m http.server 8000
```

Open http://localhost:8000/ in your browser.

## Deploy with GitHub Pages

1. Create a public repository named **`goktugparlak.github.io`**.
2. Upload these files to its root directory. Keep the `assets/` directory as is.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch** and choose `main` and `/(root)`.
5. After publication, verify the site at https://goktugparlak.github.io/.

See [README_TR.md](README_TR.md) for detailed Turkish instructions.
